### 🗨️ About
**Better Teleport** is a mod that adds a GUI-based player teleportation system to your game, making it easy and intuitive to teleport directly to other players.  
You can open the teleportation menu by pressing the **"R"** key (or any key you have assigned) while in-game.

### 🏃 Teleport System

From the **"Players"** section of the teleportation menu, you can view all active players on the server and send teleport requests to them.



<p align="center">
  <img src="https://cdn.modrinth.com/data/cached_images/caec40b31091f6d0046c944a07e7f0432c80b92e_0.webp" width="584">
</p>

Players you send a request to can either accept or decline it from the **"Pending Requests"** menu. If your request is accepted, you will be teleported directly to that player.     
However, players who are in a different dimension will not appear in the player list, and you will not be able to send teleport requests to them.
